# Электронный журнал

Готовый учебный проект на PHP + MySQL для XAMPP.

## Подключение
MySQL настроен на порт **3307**.

Адрес сайта:
`http://localhost/electronic-journal/`

## Данные
В этой версии преподаватели и студенты заменены данными из загруженных файлов:

- `Персонал.xlsx` — взяты **10 преподавателей**;
- `Контингент вктоу ПО.xls` — импортированы **все 426 студентов**;
- старые тестовые преподаватели и студенты удаляются автоматически;
- группы формируются по кодам групп из файла контингента.

## Установка
1. Распакуйте папку `electronic-journal` в `D:\XAAMP\htdocs\`.
2. Запустите Apache и MySQL в XAMPP.
3. Убедитесь, что MySQL работает на порту 3307.
4. Для старой базы просто откройте сайт — данные преподавателей/студентов заменятся автоматически один раз.
5. Для чистой установки импортируйте `database/electronic_journal.sql`, затем откройте сайт.
